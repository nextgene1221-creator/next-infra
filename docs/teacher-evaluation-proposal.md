# 講師 評価指標カタログ（依頼④・提案 2026-07-14）

オーナー要望：**評価指標（＝評価ポイント）を多数提案し、その中から採用するものをオーナーが選び、選んだ指標で講師にポイントを付与して評価したい。**

このドキュメントは「候補指標の一覧」。**採用/不採用と重みを右端に記入**してください（`採用[ ]`→`採用[x]`）。選定後に、集計＋ポイント付与の仕組み（新テーブル）を実装します。

- **算出元**は既存データのみ（追加入力を極力増やさない方針）。
- **帰属注意**＝「講師本人の努力」と「生徒側の要因」を混同しやすい指標には印。
- 集計期間は月次を想定（他候補：週次／学期）。

## 仕組みの想定（指標選定後に実装）

1. **オーナーが上表で採用指標＋重みを確定**。
2. システムが月次で各講師の**指標スコア**を自動算出（A〜Dは既存データから、E は手動入力）。
3. 合成スコアを提示 → **オーナーが最終確認してポイントを付与**（自動付与ではなく承認制。オーナー要望「こちらで選び付与」に対応）。
4. 講師別の評価履歴を残す。

**要実装（新テーブル・本番マイグレーション必要）**:
- `TeacherEvaluationMetric`（採用指標と重みの設定）
- `TeacherEvaluation`（講師・期間・指標別スコア・合成スコア・付与ポイント・確定者）
- 手動指標（E）用の入力欄

## オーナーへの確認事項

1. 上表で**採用する指標**と、ざっくりの**重み**（例：5段階／%）。
2. 集計期間（**月次**／週次／学期）。
3. 付与は**承認制**（提示→オーナーが確定）でよいか、自動付与か。
4. スコアを**講師本人に見せる**か、管理者のみか。
5. 「ポイント」は**講師に付くスコア**という理解でよいか（生徒ポイントとは別系統）。
