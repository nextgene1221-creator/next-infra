## 方針（社内メモ・送らない）

- **LINEログインは今回スコープ外**（LINE Loginチャネルは不要）。ログインは従来のメール＋パスワードのまま。
- LINEは **Messaging API による「お知らせ通知」＋「友だち追加でアカウント連携」** のみ。
- **Channel ID / Channel secret は受領済み**。この2つだけで通知トークンをシステム側で自動発行できるため、**アクセストークンを別途もらう必要はなし**。
- システム側で使う環境変数（実装フェーズで設定）: `LINE_CHANNEL_ID` / `LINE_CHANNEL_SECRET`。
- クライアントに残っている作業は **①Webhook設定 ②応答設定 ③友だち追加リンク** の3つだけ。
